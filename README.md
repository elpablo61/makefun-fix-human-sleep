[Fix Human Sleep: Funniest Patch Note](https://make.fun/bounty/u-yuki-kato-fix-human-sleep-funniest-patch-note-f6ad4c27)
bounty on make.fun ($2, judged head to head by an AI model).

## The entry

> Fixed: sleep now saves correctly. Previously, 8 hours of sleep loaded as 20 minutes and a headache.

## How it works

`main.ts` (Node 22) writes the single patch-note line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The line is
99 characters, inside the 160-character gate, and reads like a real
changelog entry: one save/load concept, concrete numbers, no explanation
of the joke.

## Run

```sh
node main.ts
cat /output/entry.txt
```
